Questions fréquentes

Tout ce que vous devez savoir sur N8Ninja

Comment connecter mon instance n8n ?

Entrez simplement votre URL et token API dans les paramètres de l'app. L'app supporte les instances n8n Cloud et auto-hébergées.

Est-ce compatible avec n8n Cloud ?

Oui, l'app fonctionne parfaitement avec n8n Cloud et toutes les instances auto-hébergées. Vous pouvez gérer plusieurs serveurs simultanément.

Puis-je déclencher des workflows depuis l'app ?

Oui ! Vous pouvez déclencher des webhooks, partager des URLs, et même intégrer vos automatisations avec Siri et les Raccourcis iOS.

L'app est-elle sécurisée ?

Absolument. Vos tokens API sont stockés de manière sécurisée sur votre appareil et ne sont jamais transmis à des serveurs tiers.

L'app supporte-t-elle plusieurs langues ?

Oui, l'app supporte plusieurs langues et s'adapte automatiquement aux préférences de votre système.

L'app est-elle open source ?

Non, mais elle est conçue pour respecter la philosophie ouverte de n8n et s'intègre parfaitement dans l'écosystème n8n.
